# Provenance and limitations

The final thesis reports 107 pairs (37 authentic, 70 accepted synthetic), not the earlier 110-pair working version. The six final data and result files in this archive are byte-for-byte copies of the original ZIP files. The final thesis PDF is also copied unchanged. Earlier 110-row per-model workbooks and obsolete tests are excluded; the final consolidated workbook contains all four final model outputs. Raw generation candidates and rejection annotations were not found as a separate complete workbook in the supplied archives; aggregate counts are documented in the thesis.

The archived prompt contains six rules, including an explicit instruction not to correct other elements; the thesis prints five rules. The archived prompt is preserved unchanged. API script filenames were kept, stale corpus and output filenames updated, and token-like strings replaced in the earlier packaging. Evaluation script logic was retained unchanged. Python comments and docstrings were standardized in French. The token-level alignment approach adapts the methodology of Lin Song (2025), as documented in Chapter 9 of the final thesis; this attribution remains distinct from implementation comments. Aggregate tables come from the original workbook. The full original corpus has not been rerun in this packaging; historical data are retained unmodified. Review corpus rights, code ownership and research dissemination authorization before making the repository public.
